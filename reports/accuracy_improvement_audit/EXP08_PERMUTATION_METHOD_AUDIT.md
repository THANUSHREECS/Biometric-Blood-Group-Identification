## 1. Executive Summary

This audit evaluates the statistical validity of the permutation test implemented in [`evaluate.py`](file:///c:/Users/thanu/OneDrive%20-%20Don%20Bosco%20Institute%20of%20Technology/major%20project/experiments/exp08_dermatoglyphic_minutiae/evaluate.py) for EXP-08. 

### Core Audit Finding:
The existing permutation test shuffles ground truth labels against **fixed out-of-fold predictions** generated by models trained once on the original data. 
- **Methodological Distinction:** Shuffling labels against fixed predictions tests whether the *specific set of static predictions* $\hat{y}$ is independent of $Y$. It does **not** test whether the *learning algorithm* $f(X) \to \hat{Y}$ can extract spurious associations from uninformative data.
- **The Valid Machine Learning Null Test:** A complete test of the hypothesis $H_0: X \perp\!\!\!\perp Y$ requires **repeating the entire machine learning pipeline** (cross-validation partitioning, in-fold imputation, in-fold scaling, and model refitting) for every permuted label draw.
- **Computational Feasibility:** Because classical models on the $(80, 24)$ feature matrix train quickly, running 1,000 full pipeline refit permutations requires only **$\approx 12.5\text{ minutes}$** of CPU runtime.
- **Impact on Substantive Conclusions:** The current observed Random Forest balanced accuracy ($27.06\%$) is already statistically nonsignificant ($p = 0.3250$) under the fixed-prediction test. Under full refitting, model adaptation to training noise typically increases null variance, which will maintain or increase the $p$-value. Thus, the substantive finding (lack of predictive signal beyond baseline) is stable, but adopting the complete pipeline refit is necessary for formal statistical correctness.

## 2. Analysis of the Existing Implementation

### A. Code Inspection (`evaluate.py: participant_label_permutation_test`)
Lines 99–123 of [`evaluate.py`](file:///c:/Users/thanu/OneDrive%20-%20Don%20Bosco%20Institute%20of%20Technology/major%20project/experiments/exp08_dermatoglyphic_minutiae/evaluate.py) implement the following logic:

```python
def participant_label_permutation_test(y_true, y_probs, n_permutations=1000, seed=42):
    rng = np.random.RandomState(seed)
    y_pred = np.argmax(y_probs, axis=1)  # FIXED PREDICTIONS FROM REAL-DATA TRAINING
    obs_bal = balanced_accuracy_score(y_true, y_pred)
    
    null_bal = np.zeros(n_permutations, dtype=np.float32)
    for i in range(n_permutations):
        perm_y = rng.permutation(y_true)  # PERMUTE TRUE LABELS
        null_bal[i] = balanced_accuracy_score(perm_y, y_pred)  # EVALUATE AGAINST FIXED PREDICTIONS

    p_bal = float(np.mean(null_bal >= obs_bal))
    return {"observed_balanced_accuracy": obs_bal, "perm_p_balanced_accuracy": p_bal, ...}
```

### B. What Hypothesis Does This Actually Test?
This procedure tests the **prediction-level null hypothesis**:
$$H_0^{\text{pred}}: \text{The fixed prediction vector } \hat{y} \in \{0, 1, 2, 3\}^{80} \text{ is statistically independent of the target vector } Y.$$
Under this formulation:
- $\hat{y}$ is treated as a deterministic, exogenous set of guesses.
- Permuting $Y$ generates a null distribution of balanced accuracy for those specific guesses against random label assignments.
- This is analogous to a non-parametric Fisher-Pitman permutation test on a contingency table.

## 3. Statistical Limitations of Shuffling Against Fixed Predictions

In supervised machine learning, testing fixed predictions has two major limitations:

### 1. Omission of Model Capacity & Noise-Fitting Under the Null
In reality, the supervised classifier (Random Forest with 100 trees, depth 4, and balanced class weights) is an adaptive algorithm. 
- When provided with features $X$ and permuted labels $Y_\pi$, an adaptive algorithm will attempt to find patterns in the training folds.
- If $X$ and $Y_\pi$ are independent, any discovered patterns are purely spurious.
- When evaluated out-of-fold, these spurious patterns will fail to generalize, but the distribution of out-of-fold predictions will reflect the algorithm's inductive bias, tree depth constraints, and class weighting behavior under noisy conditions.
- Shuffling post-hoc assumes that the predictions the model made when trained on $Y_{\text{real}}$ are identical to the predictions it would make when trained on $Y_\pi$. This assumption is invalid.

### 2. Underestimation of Null Variance
Because fixed predictions $\hat{y}$ have a fixed marginal class distribution (e.g., Random Forest predicted 17 A+, 3 AB+, 24 B+, 36 O+), the post-hoc permutation distribution is constrained to the combinations of that specific fixed vector against permutations of $Y$.
When the model is refitted on $(X, Y_\pi)$ in each permutation, the marginal distribution of predictions can vary across permutations. This additional source of estimation variance is omitted in the fixed-prediction formulation.

## 4. The Intended Scientific Null Hypothesis

The formal null hypothesis of EXP-08 is that **friction ridge dermatoglyphic features contain no predictive information about ABO blood groups**:
$$H_0^{\text{biomarker}}: P(Y \mid X) = P(Y) \iff X \perp\!\!\!\perp Y$$

Under $H_0^{\text{biomarker}}$, the data generating process pairs participant feature vectors $X_i$ with blood-group labels $Y_i$ purely at random. 
To construct a valid test of $H_0^{\text{biomarker}}$ for the machine learning model $f(\cdot)$, the test statistic must be the performance of the **entire training and evaluation pipeline applied to data generated under $H_0$**:
$$T(X, Y) = \text{BalAcc}_{\text{OOF}}\Big(\mathcal{M}\big(\mathcal{D}_{\text{train}}\big), \mathcal{D}_{\text{val}}\Big)$$
where $\mathcal{M}$ includes in-fold median imputation, in-fold feature scaling, fold partitioning, and classifier fitting.

The valid empirical $p$-value is:
$$p = \frac{1 + \sum_{b=1}^{B} \mathbb{I}\left( T(X, Y_{\pi_b}) \ge T(X, Y) \right)}{B + 1}$$
where the $+1$ pseudo-count ensures an unbiased test with exact type I error control (Davison & Hinkley, 1997; Phipson & Smyth, 2010).

## 5. Fold Construction & Class Stratification Under Permutation

When labels $Y$ are permuted to $Y_\pi$, how should cross-validation folds be handled?

### A. Participant-Level Class Counts
Because permutation is a bijective shuffle of the 80 participant labels, the overall cohort class distribution ($19\text{ A+}, 7\text{ AB+}, 25\text{ B+}, 29\text{ O+}$) is strictly preserved in every permutation $b$.

### B. Fold Stratification Under $Y_\pi$
Two options exist for fold partitioning under permuted labels:
1. **Fixed Fold Membership (Keep original participant assignments):**
   - Each fold keeps the exact same 16 participants.
   - *Limitation:* With only 7 AB+ participants in the cohort, a random permutation across 80 participants will frequently assign 0 AB+ participants to one or more validation folds (the probability that a 16-sample fold receives 0 AB+ samples is $\approx \binom{73}{16} / \binom{80}{16} \approx 18.5\%$).
   - If a validation fold has 0 AB+ samples, fold-specific balanced accuracy cannot be computed without ad-hoc rules.
2. **Re-Stratified Partitioning under $Y_\pi$ (Recommended Standard):**
   - For each permutation $b$, `StratifiedGroupKFold(n_splits=5, shuffle=True, random_state=SEED)` is executed on $(X, Y_{\pi_b}, \text{groups})$.
   - This ensures that every fold under the null receives a representative draw of classes (e.g., 1–2 AB+ per fold), matching the exact structural conditions of the real-data evaluation.
   - Re-stratification is mathematically appropriate because stratification is part of the experimental protocol, not a property of the underlying population.

## 6. Recommended Valid Testing Procedure & Computational Cost

### A. Recommended Algorithm
```
For permutation b = 1 to B (e.g., B = 1,000):
  1. Generate participant label permutation: Y_perm = rng.permutation(Y)
  2. Partition (X, Y_perm) into 5 folds via StratifiedGroupKFold
  3. For fold k = 1 to 5:
       a. X_tr, Y_tr = training fold data
       b. X_val, Y_val = validation fold data
       c. Fit SimpleImputer(strategy="median") on X_tr
       d. Fit StandardScaler() on X_tr (for Logistic Regression)
       e. Fit Classifier (Logistic Regression or Random Forest) on X_tr, Y_tr
       f. Predict class probabilities on X_val
  4. Aggregate out-of-fold predictions for all 80 participants
  5. Compute BalAcc_null[b] = balanced_accuracy_score(Y_perm, OOF_preds)
  6. Compute MacroF1_null[b] = f1_score(Y_perm, OOF_preds, average="macro")

Compute exact p-value:
  p = (1 + sum(BalAcc_null >= BalAcc_observed)) / (B + 1)
```

## 7. Assumptions and Limitations of the Recommended Procedure

1. **Exchangeability Assumption:**
   Permutation tests assume that under $H_0$, participant labels are exchangeable across the 80 development participants. Because participants are biologically independent individuals and all 3 impressions per participant were collapsed prior to permutation, the exchangeability assumption holds.
2. **Minority Class Granularity ($N_{AB+} = 7$):**
   With only 7 AB+ participants, the resolution of AB+ recall under any single permutation is in increments of $1/7 \approx 14.29\%$. Even under permutation, balanced accuracy will exhibit discrete steps.
3. **Invariance of Substantive Findings:**
   The observed Random Forest balanced accuracy was $27.06\%$. In the fixed-prediction test, the null mean was $25.19\%$ with $p = 0.3250$.
   Under full refitting, allowing the model to fit training-fold noise will spread the null distribution variance, typically shifting the upper tail higher. Consequently, the empirical $p$-value under the full refit will almost certainly remain $\gg 0.05$, confirming that the substantive scientific conclusion (absence of predictive signal) is not an artifact of the permutation method.
